## Development
- Make sure you have Python 3.12 installed
- Clone this repo
- Download TorusNotched-Regular.ttf and put in ./Window/font (I don't provide one though)
- Install packages
    ```
    pip install -r requirements.txt
    ```
- run/debug main.py
